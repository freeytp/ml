Implement Gradient Descent to minimize y = (x + 3)^2, starting from x = 2.

1. KEY CONCEPT
Gradient Descent is an optimization algorithm. It repeatedly updates x in the direction opposite to the derivative to reduce the function value.

Objective function:
    f(x) = (x + 3)^2

Derivative:
    f'(x) = 2(x + 3)

Minimum:

2. UPDATE FORMULA
    x_new = x_old - learning_rate * gradient

  3. Store (x, f(x)) in path.
  4. Print progress at the selected interval.

- Run the algorithm and compare different learning rates.
