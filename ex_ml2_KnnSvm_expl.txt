5) STEP 5 – K-NEAREST NEIGHBORS (KNN)
KNN is a supervised, instance-based classification algorithm.
It finds the K closest training examples to a new email and predicts the majority class among those neighbours.

EUCLIDEAN DISTANCE FORMULA
d(x,y) = sqrt( sum from i=1 to n of (x_i - y_i)^2 )

- x_i and y_i are feature values of two emails.
- n is the number of features.
- Smaller distance means more similar feature vectors.
- Majority voting among the 5 nearest neighbours decides the class.

6) STEP 6 – SUPPORT VECTOR MACHINE (SVM)

Meaning:

LINEAR HYPERPLANE
w^T x + b = 0

- w = weight vector.
- x = input feature vector.
- b = bias.
- Support vectors are training points closest to the separating boundary.
- Margin is the distance between the boundary and the nearest points from each class.

7) STEP 7 – EVALUATION METRICS
The evaluate() function prints four metrics.

Let:
TP = actual spam correctly predicted as spam.
TN = actual normal correctly predicted as normal.
FP = actual normal incorrectly predicted as spam.
FN = actual spam incorrectly predicted as normal.

ACCURACY
(TP + TN) / (TP + TN + FP + FN)
Overall proportion of correct predictions. Higher is generally better.

PRECISION
TP / (TP + FP)
Out of emails predicted as spam, how many were actually spam? Higher means fewer normal emails are wrongly marked as spam.

RECALL
TP / (TP + FN)
Out of actual spam emails, how many were detected? Higher means fewer spam emails are missed.

F1-SCORE
2 × (Precision × Recall) / (Precision + Recall)
Harmonic mean of precision and recall. Higher is generally better, especially when classes are imbalanced.

zero_division=0:
If a metric denominator is zero, return 0 instead of producing a divide-by-zero warning.
