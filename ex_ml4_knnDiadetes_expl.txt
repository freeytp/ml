StandardScaler makes features comparable because KNN uses distances.

fit_transform learns statistics from training data; transform applies

4. KNN ALGORITHM
K-Nearest Neighbors predicts a class by finding the K closest
training records and using majority voting.

Your code:
knn = KNeighborsClassifier(n_neighbors=5)
knn.fit(X_train, y_train)
y_pred = knn.predict(X_test)

K=5 means five nearest patients are considered.
fit() stores training examples and labels.
predict() predicts the test classes.

Euclidean distance:
d(P,Q) = sqrt(sum((Pi - Qi)^2))

Example: If the five neighbors have labels 1,1,0,1,0, the majority
is 1, so the predicted class is diabetic.

5. CONFUSION MATRIX AND METRICS

cm = confusion_matrix(y_test, y_pred)
accuracy = accuracy_score(y_test, y_pred)
error_rate = 1 - accuracy
precision = precision_score(y_test, y_pred, zero_division=0)
recall = recall_score(y_test, y_pred, zero_division=0)

Confusion matrix:
                 Predicted 0    Predicted 1
Actual 0              TN             FP
Actual 1              FN             TP

TN: non-diabetic correctly predicted.
TP: diabetic correctly predicted.
FP: non-diabetic incorrectly predicted as diabetic.
FN: diabetic incorrectly predicted as non-diabetic.

Accuracy = (TP + TN) / (TP + TN + FP + FN)
Error rate = 1 - Accuracy
Precision = TP / (TP + FP)
Recall = TP / (TP + FN)

Accuracy = overall correctness.
Error rate = proportion of wrong predictions.
Precision = how many predicted diabetic cases are truly diabetic.
Recall = how many actual diabetic cases are found.

zero_division=0 returns zero if a metric is undefined due to
division by zero.
