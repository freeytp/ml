3) DISTANCE – HAVERSINE FORMULA
Pickup and drop-off are given as latitude/longitude. Haversine calculates the approximate great-circle distance on Earth.

Formula:
a = sin²(Δlat/2) + cos(lat1) cos(lat2) sin²(Δlon/2)
distance = 2 R asin(√a)

R = 6371 km (Earth's approximate radius).
Latitude/longitude must be converted from degrees to radians before using trigonometric functions.

Typical implementation:
def haversine(lat1, lon1, lat2, lon2):
    R = 6371
    lat1, lat2 = np.radians(lat1), np.radians(lat2)
    dlat = lat2 - lat1
    dlon = np.radians(lon2 - lon1)
    a = np.sin(dlat/2)**2 + np.cos(lat1)*np.cos(lat2)*np.sin(dlon/2)**2
    return 2 * R * np.arcsin(np.sqrt(a))

df["distance_km"] = haversine(
    df["pickup_latitude"], df["pickup_longitude"],
    df["dropoff_latitude"], df["dropoff_longitude"])
df = df[df["distance_km"] > 0]

Python reminders:
- def defines a function; return sends back its result.
- ** means power (x**2 = x squared).

4) OUTLIERS – IQR METHOD
Q1 = 25th percentile; Q3 = 75th percentile
IQR = Q3 - Q1
Lower limit = Q1 - 1.5 × IQR
Upper limit = Q3 + 1.5 × IQR
Values outside these limits are potential outliers.

Code:
for col in ["fare_amount", "distance_km"]:
    q1 = df[col].quantile(0.25)
    q3 = df[col].quantile(0.75)
    iqr = q3 - q1
    df = df[df[col].between(q1 - 1.5*iqr, q3 + 1.5*iqr)]

Remember:
- quantile(0.25) gives Q1; quantile(0.75) gives Q3.
- between(low, high) keeps values inside the limits.
- IQR is robust to extreme values and is commonly used for outlier detection.

8) EVALUATION FORMULAS
R² (coefficient of determination):
R² = 1 - [sum((actual - predicted)²) / sum((actual - mean(actual))²)]
Closer to 1 is generally better. It can be negative if the model is worse than predicting the mean.

MAE (Mean Absolute Error):
MAE = (1/n) × sum(|actual - predicted|)
Average absolute prediction error. Lower is better.

MSE (Mean Squared Error):
MSE = (1/n) × sum((actual - predicted)²)

RMSE (Root Mean Squared Error):
RMSE = √MSE
Lower is better; large errors are penalized more because errors are squared.

Code:

    print("RMSE:", round(np.sqrt(mean_squared_error(y_test, pred)), 3))
