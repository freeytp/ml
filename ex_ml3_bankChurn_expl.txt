6. WHAT IS AN ARTIFICIAL NEURAL NETWORK?
An ANN is a machine-learning model made of connected artificial neurons. It has:
- Input layer: receives features.
- Hidden layer(s): learn patterns.
- Output layer: produces the prediction.

A neuron calculates:
z = w1*x1 + w2*x2 + ... + wn*xn + b
output = activation(z)

x = input, w = learned weight, b = bias.
During training, weights and biases are adjusted to reduce prediction error.

7. BASELINE MODEL
Exact architecture:
initial_model = Sequential([
    Input(shape=(X_train.shape[1],)),
    Dense(64, activation="relu"),
    Dense(32, activation="relu"),
    Dense(1, activation="sigmoid")
])

Input(shape=(X_train.shape[1],))
    Number of input values equals the number of feature columns. shape[1] means number of columns; the comma makes a one-element tuple.

Dense(64, activation="relu")
    First fully connected hidden layer with 64 neurons.

Dense(32, activation="relu")
    Second hidden layer with 32 neurons.

Dense(1, activation="sigmoid")
    One output neuron. Sigmoid produces a value between 0 and 1, treated as the probability of class 1 (customer exits).

ReLU formula: ReLU(x) = max(0, x)
It returns zero for negative input and the input itself for positive input.

Sigmoid formula: sigmoid(x) = 1 / (1 + e^(-x))
It maps values into the range 0 to 1.

One output neuron is used because this is binary classification.

8. COMPILE THE MODEL
initial_model.compile(
    optimizer="adam",
    loss="binary_crossentropy",
    metrics=["accuracy"]
)

Adam: optimizer that updates weights to reduce loss.
Binary cross-entropy: loss function for binary classification.
Formula:
Loss = -[y*log(p) + (1-y)*log(1-p)]
y = actual class (0/1); p = predicted probability for class 1.
accuracy: reports the fraction of correct predictions.

initial_model.summary() displays each layer, output shape and trainable parameter count.

10. IMPROVED MODEL WITH DROPOUT
Exact architecture:
model = Sequential([
    Input(shape=(X_train.shape[1],)),
    Dense(64, activation="relu"),
    Dropout(0.3),
    Dense(32, activation="relu"),
    Dropout(0.2),
    Dense(16, activation="relu"),
    Dense(1, activation="sigmoid")
])

Architecture:
Input -> Dense(64) -> Dropout(0.3) -> Dense(32)
-> Dropout(0.2) -> Dense(16) -> Dense(1)

Compared with baseline, it adds a 16-neuron hidden layer and two Dropout layers.

Dropout randomly sets a fraction of layer outputs to zero during training. This discourages over-reliance on particular neurons and can reduce overfitting.
Dropout(0.3) means 30%; Dropout(0.2) means 20%.
Dropout is disabled during normal prediction.

Compile with the same optimizer, loss and metric:
model.compile(optimizer="adam", loss="binary_crossentropy", metrics=["accuracy"])

The word improved describes the alternative design being tested. It does not guarantee better test accuracy. Compare actual results.

13. EVALUATION
The original code uses accuracy and confusion matrix.

Accuracy = (TP + TN) / (TP + TN + FP + FN)

TP = predicted exited and actually exited.
TN = predicted stayed and actually stayed.
FP = predicted exited but actually stayed.
FN = predicted stayed but actually exited.

Confusion matrix (class order [0,1]):
                 Predicted
                 0       1
Actual 0         TN      FP
Actual 1         FN      TP

In scikit-learn:
[[TN, FP],
 [FN, TP]]

The evaluate() function receives a model name and predictions, calculates accuracy_score(y_test, prediction), calculates confusion_matrix(y_test, prediction), and prints the results.

IMPORTANT: The original code does not calculate precision, recall or F1-score. These may be added as optional metrics, but do not say they are already included.

Accuracy can be misleading when classes are imbalanced. The confusion matrix reveals the types of mistakes.
